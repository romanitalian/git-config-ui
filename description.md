# Pull request title

**feat(ui): branding, About screen, and icon pipeline**

## Summary

This PR refreshes **GitConfigs** branding and packaging: a **sidebar logo**, an **About** section with version and GitHub link, **Xcode asset catalog** icons for the app target, and a **Makefile-driven** flow to regenerate **`.icns`**, in-app **AppLogo**, and catalog images from a raster or SVG source.

## What changed

- **Sidebar:** Logo strip above the section list, **divider** under the logo, **no duplicate app title** under the logo, slight **top padding** before the first row (`Users`).
- **Navigation:** New **About** item; **About** detail uses **`GitConfigs`** as the navigation title and keeps the **“About”** section header inside the form.
- **Versioning:** **`AppMetadata`** reads `CFBundleShortVersionString` with a fallback; **`project.yml`** sets `MARKETING_VERSION` / `CURRENT_PROJECT_VERSION`; **`make bundle`** Info.plist aligned to **1.0.0** / build **1**.
- **Icons & assets:** **`Assets/logo-source.png`** as preferred master for **`make icon`** (`sips`); fallback to **`Assets/icon.svg`** via **`rsvg-convert`**; **`make import-logo`** (ImageMagick) to square-crop repo-root **`logo.png`**; sync **`AppLogo`** into SPM **`Resources`** and **`AppLogo.imageset`**; **`AppIcon.appiconset`** for Xcode.
- **SPM:** **`GitConfigsLib`** **`Resources`**; **`GitConfigs`** executable **`exclude: Assets.xcassets`** so SPM does not treat the catalog as stray sources.
- **Repo hygiene:** **`.gitignore`** includes **`Assets/AppIcon.iconset/`** (regenerated by `make icon`).

## How to verify

- `swift test`
- `make import-logo` (optional) → `make icon` → `make bundle` / run from Xcode after `xcodegen generate` if you use the Xcode project
- Launch app: sidebar logo, **About** content, Dock/bundle icon after **`make install`**

## Notes for reviewers

- **`logo.png`** / **`Assets/logo-source.png`** are intentional sources for branding; **`AppIcon.iconset`** is intentionally **not** tracked.
